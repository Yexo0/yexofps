# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

yexofps.org — personal site of Baptiste Dauvergne ("Yexo" on the creator/gaming side). Dashboard-style site organised in 7 "spaces": Home, Projects, Career, Lab (homelab), Gaming (ranks + live Valorant tracker), Creator (edits, partners, Y-Services shop), Contact. Bilingual via next-intl: **English by default** (first visit is always English, whatever the browser language), French through the language button; the last choice is remembered. Self-hosted on an Ubuntu VPS.

Never mention the work-study employer, its name or its city anywhere (texts, translations, metadata, Lab). The role is written as "Alternant gestionnaire d'infrastructures informatiques au sein d'une DSI".

Only the first name "Baptiste" appears on the pages (`SITE.displayName`: hero labels, career title, footer). The full name (`SITE.author`) stays in metadata only.

Never remove texts, features or animations without asking first: restyle and optimise them instead.

## Tech Stack

- **Framework:** Next.js 16 (App Router, Turbopack), TypeScript, React 19
- **Styling:** Tailwind CSS v4; design tokens and shared components in `src/app/globals.css`, colour tokens generated by `src/lib/theme.ts`
- **Colours:** one accent, the Yexo red (`PALETTE` in `src/config/theme.ts`: `#FF4655` for small accents, `#E02F3D` for filled buttons with white text, AA). Neutrals: black background, grey glass surfaces (`--surface` translucent, `--surface-2/3` light overlays, `--surface-solid` opaque for dialogs and sticky bars). Dark by default, light available (`data-theme`, stored in `localStorage`).
- **Fonts:** Geist + Geist Mono (`geist` package) for text; Inter Tight (`src/app/fonts/inter-tight-latin.woff2`, OFL, `next/font/local`, variable 100–900) for titles and big figures via `.display` / `font-display`. Mono only for real code (hostnames, IPs, codes, terminal). No network at build.
- **Motion:** CSS first (transitions/keyframes on transform/opacity, tokens `--ease-*`, `--dur-*`), React `<ViewTransition>` between pages; anime.js for the project cover stroke drawing (`src/lib/anime.ts`); `motion` is installed (types/helpers in `src/lib/motion.ts`).
- **3D:** three.js + React Three Fiber + drei, client-only and lazy (`next/dynamic`), in `src/components/three/`. Models in `public/models/` (optimized with `npx @gltf-transform/cli optimize in.glb out.glb --compress meshopt --texture-compress webp --texture-size 2048`; phone variant `vandal-lite.glb` = texture 1024 + `simplify --ratio 0.5 --error 0.001`, then `meshopt`), credits in `MODEL_CREDITS` (`site.ts`), shown in the footer with the Riot Games notice.
- **UI primitives:** Radix (`radix-ui`: Dialog, Accordion, Tabs), Lucide icons, brand SVGs in `src/components/icons/brands.tsx`
- **i18n:** next-intl, `/en/...` and `/fr/...` prefixes (`localePrefix: "always"`, default `en`, `localeDetection: false`). `src/proxy.ts` sends unprefixed URLs to the `NEXT_LOCALE` cookie's language or English; the language button (`UIProvider.switchLocale`) writes that cookie for a year.
- **External APIs:** HenrikDev Valorant API via `/api/valorant`; Lanyard (live Discord presence) via `/api/presence`. Own live endpoint: `/api/host` (server figures, no hostname/IP)

### Config — single sources of truth (`src/config/`)

- `theme.ts` — the red accent (`PALETTE`) and default theme
- `site.ts` — every URL (socials, emails, affiliate links, Payhip, TikTok videos), age (`PROFILE`), featured edit (`FEATURED_EDIT`: local `video` + `poster` in `public/videos/` with a custom player — used only if the file exists at build, source attached only when the player approaches the viewport, poster through next/image, autoplays muted only while on screen; files in `public/videos/` and `public/models/` are cached one year `immutable` (`next.config.ts`), so rename them (v2, v3…) whenever they change; `aspect` "landscape" switches the home to a wide 16:9 card; otherwise TikTok embed on click), tracker account, Valorant peak, ranks, setup, products (`exampleUrl` / `previewUrl` buttons only show when set), reviews, `MODEL_CREDITS`
- `spaces.ts` — the 7 spaces (order = number = keyboard shortcut); `mobile` puts a space in the mobile dock (the others go in "More"); `aliases` attach extra pages to a space
- `projects.ts` — every project (slug, status, year, stack, media in `public/images/projects/` and `public/videos/projects/`, links); texts in `messages/*.json` under `projects.items.<slug>`
- `lab.ts` — the whole homelab (VLANs, hosts, VMs, map, `LAB_SCENARIOS` replayed on the map). Invented items carry `placeholder: true` + a comment
- `career.ts` — timeline, skills, missions, PDF guides, BTS network map and `BTS_SCENARIOS`
- `valorant-settings.ts` — every in-game Valorant setting read from screenshots (tabs → sub-tabs → sections → rows), crosshair (preview + profile code), display. Sens/DPI come from `MY_SENS` in `site.ts`
- `now.ts` — weekly schedule (weekday / Saturday / Sunday, from wake-up to next wake-up) and availability per activity. The /now status, the Contact status card and the footer "Right now" chip are computed client-side in Europe/Paris time (`src/lib/now.ts`, `useNow`): no manual update. `SPOTIFY_URL` in `site.ts` shows the Spotify button during the music slot when set. Live Discord presence (`DISCORD_USER_ID` in `site.ts`, Lanyard): a game/app listed in `PRESENCE_ACTIVITIES` overrides the schedule, Spotify listening shows the current track, the Discord avatar (static, with profile decoration and status dot; DND is shown as online) replaces the activity icon on /now and on Contact; unlisted activities never leave the server (`src/lib/presence.ts`, 15 s server cache, client polls every 30 s while visible)

All visible text lives in `messages/en.json` and `messages/fr.json` (same keys in both files, matching the config ids). Card `subtitle` props (shell commands) are kept in the code but no longer displayed; Valorant setting labels stay literal (copied from the English game client).

### Tracker data flow

1. `useValorantTracker` fetches `/api/valorant?region=eu&name=Fallen%20angel&tag=yexo&mode=unrated&size=10` (params from `TRACKER` in `site.ts`)
2. The API route proxies HenrikDev with `HENRIK_API_KEY` and reduces each match to the player's stats
3. States: loading (skeleton) / ready / empty / error (rate limit, unavailable incl. missing key, network). The peak is always shown.
4. Auto-refresh every 90 s, manual refresh with a 25 s cooldown

### Sensitivity converter math (`src/lib/converter-math.ts`, unchanged)

Yaw: CS2 `0.022`, Valorant `0.07`, Apex `0.022`, OW2 `0.0066`. `cm360 = (360 × 2.54) / (dpi × sens × yaw)`.

## Design rules — "premium doux"

Sober, premium, Apple-like; Valorant only as subject matter, never a copy of the game's UI or art. Black background with the topographic Backdrop, glass cards (translucent grey, top sheen, 1 px edge, 22 px radius → 28 px from `md`), no borders, no cut corners. One accent, red: primary button (filled pill), current location (red icon in the rail), live state, small dots, major contour lines, the 3D halo. Selected states (in-page nav, tabs, segmented controls, scenario bar, profile switch) are white pills with dark text, not red blocks. Buttons are pills (`.btn-primary` red, `.btn-tonal` thin outline, `.btn-ghost`), chips and tags too. Titles and key figures in Inter Tight (600–700, tight tracking, sentence case), body in Geist, small labels in grey Geist sentence case (`.label`), never uppercase mono. System cursor.

Bento grid of cards (6 columns from `md`, 12 from 1024 px = Tailwind `lg`, so `lg:col-span-*` always matches the grid). Space between groups of sections: `.group-start` on every card of a group's first row (`-md` / `-lg` variants for a card that is only first in its row from that breakpoint); cards inside a group stay close. The footer is detached the same way.

Placement is deliberate, top to bottom: what matters most first and biggest. Two home profiles: Yexo (`/`) and Baptiste (`/baptiste`, no Valorant: infra + After Effects, background then fastfetch, Gaming tile last). Home = full-height hero (huge name letter by letter, one line, actions, profile switch, 3D object on a soft red halo with two small callouts, key figures strip), then proof (featured edit, live stats), then the other spaces as large tiles. Gaming = current rank huge, peak with the swinging Radiant buddy, other games beside it (Radiant peak a few months in 2024, now Immortal 3, only shown alongside the other ranks); creator side is "monteur vidéo (Valorant)". 3D only where it carries meaning (home heroes, peak tile, Creator title card); no 3D characters.

Animations (rich but never gratuitous): letter-by-letter hero title, count-up figures, card reveal + cascading content, rail opening with cascading titles and the logo forming, sliding active pills, page transitions (React `<ViewTransition>`, old page fades and recedes, new one rises; the h1 card morphs as `lead-card`), network scenarios, edit timeline, dot-matrix digits, project covers drawing themselves, 3D intros on desktop. Everything is disabled or frozen with `prefers-reduced-motion`; no particles, emojis in the UI, blinking text or "hacker" clichés. Contrast AA in both themes.

## Performance

- Cards are glass without `backdrop-filter` (the faint animated lines show through; re-blurring them on every frame would cost a lot); `backdrop-filter` only on the two small floating panels (rail, mobile dock); dialogs and sticky bars use the opaque `--surface-solid`. Animate `transform`/`opacity` only (the rail opens with `clip-path`).
- Background: `Backdrop` = discreet topographic contour lines (WebGL shader: simplex noise, constant-width antialiased lines, one line in four red) drifting slowly on its own (no mouse/scroll reaction), over a fixed CSS red glow; 30 fps, up to 1.5 device px per CSS px, paused when the tab is hidden, single still frame with reduced motion or software WebGL (half resolution), started after load + idle.
- 3D posters: each 3D slot (home heroes, peak buddy, Creator logo) ships a transparent poster of its frozen scene (`public/images/hero/*-vN.webp`; rename on every new capture) in the HTML. Desktop with a real GPU (`html[data-gpu]`, probed before first paint by `themeScript`: ≥ 1024 px, fine pointer, no reduced motion, hardware WebGL): the poster is hidden and the 3D arrives with its intro animation — keep these intros. Phones: poster first, the scene starts from the poster pose and crossfades in (`.stage[data-live]`). Software WebGL (e.g. PageSpeed), no WebGL or reduced motion: three.js is never downloaded, the poster stays (also shown again if the 3D stalls or freezes: `data-fallback`).
- First-screen cards are revealed before hydration by `earlyRevealScript` (IntersectionObserver, no forced layout). CSS is inlined in the HTML (`experimental.inlineCss`); Next's legacy polyfills are aliased to `src/lib/polyfills.ts`; `images.imageSizes` includes 448 and `images.qualities` allows 45 (ambient tile images) and 75.
- WebGL canvases render only when on screen and the tab is visible; models compressed (meshopt + webp); three.js loaded after first paint.
